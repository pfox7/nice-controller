🔌 Силовая часть
SSR:

Вход «+» → резистор 220 Ом → D3

Вход «-» → GND

Силовой контакт 1 → L' (фаза после датчика ACS712)

Силовой контакт 2 → Провод A двигателя

Ноль N → Провод B двигателя (постоянно подключён)

🔌 Реле RL (рабочий конденсатор)
Используем канал 1 модуля реле (перекидной контакт SPDT).

IN1 → D5

Vcc → +5V

GND → GND

COM RL → Вывод 2 Cp + COM K3

NO RL → Провод A двигателя

NC RL → Провод B двигателя

🔌 Реле K3 (пусковой конденсатор)
Используем канал 2 модуля реле (нормально разомкнутый контакт NO).

IN2 → D9

Vcc → +5V

GND → GND

COM K3 → COM RL (та же точка)

NO K3 → Вывод 2 Cп

🔌 Конденсаторы
Рабочий Cp:

Вывод 1 → Провод C двигателя

Вывод 2 → COM RL

Пусковой Cп:

Вывод 1 → Провод C двигателя

Вывод 2 → NO K3

🔌 Концевые выключатели
Общий → GND

FCA → D7

FCC → D6

🔌 Датчик тока ACS712
Ip+ → L (фаза от автомата)

Ip- → L' (на SSR)

Vcc → +5V

GND → GND

Vout → A4
